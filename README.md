# 🛵 Мигом — сервис доставки

Веб-сервис доставки «купи и привези» с двумя ролями: **клиент** и **курьер**.

- **Фронтенд:** React 19 + Vite, Leaflet (карта OpenStreetMap), Socket.IO
- **Бэкенд:** Node.js + TypeScript + Express + Socket.IO, PostgreSQL через Prisma, вход по email и паролю (bcrypt + JWT), валидация zod
- **Тесты:** vitest + supertest на отдельной тестовой базе
- **Маршруты:** по дорогам через публичный OSRM; если он недоступен — прямыми линиями

## Возможности

**Клиент**
- карта с магазинами: выбор магазина и точки доставки кликом;
- оформление заказа: список покупок, адрес, комментарий, расчёт стоимости и предпросмотр маршрута;
- отслеживание: маршрут на карте и живое положение курьера, этапы заказа;
- оценка курьера после доставки.

**Курьер**
- карта со свободными заказами (метка показывает награду в баллах);
- по клику на метку: рейтинг клиента, что купить и куда доставить, маршрут курьер → магазин → клиент, длина и время;
- подтверждение выбора заказа, чек-лист покупок, статусы «куплено» / «доставлено»;
- положение: клик по карте или геолокация браузера; демо-кнопка «проехать маршрут автоматически»;
- оценка клиента после доставки.

**Геймификация**
- взаимный рейтинг клиентов и курьеров, таблица лидеров;
- 16 достижений (для клиентов, курьеров и общие) с бонусными баллами и прогрессом;
- баллы: курьеру — за доставку (зависит от расстояния) и оценки 5★, клиенту — 5% от суммы заказа;
- магазин призов: рамка аватара, бесплатная доставка, скидка 10%, кофе, кино, термосумка, powerbank и др.

## Демо-режим

Страница `/demo` показывает клиента (Анна) и курьера (Дмитрий) рядом. Демо-данные (пользователи с историей,
рейтингами и стартовыми баллами, 4 открытых заказа) создаются при первом запуске сервера и по кнопке «Сбросить демо».
Кнопка **«Автосценарий»** проигрывает весь цикл: заказ → курьер принимает → едет в магазин → везёт клиенту → доставлено.

## Запуск

Нужны Node.js 20+ и PostgreSQL 14+ (проверено на 18).

1. Установите зависимости фронтенда и сервера:

   ```bash
   npm install
   ```

2. Скопируйте `server/.env.example` в `server/.env` и впишите пароль пользователя `postgres`
   (и любой длинный `JWT_SECRET`). Базы `migom` и `migom_test` Prisma создаст сама.

3. Примените миграции:

   ```bash
   npm run db:deploy --prefix server
   ```

4. Запустите фронтенд и API:

   ```bash
   npm run dev
   ```

Откройте http://localhost:5173 (API работает на порту 3001). Демо-данные создаются при первом запуске.
Демо-аккаунты: `demo-customer@demo.migom` и `demo-courier@demo.migom`, пароль `demo12345`.

### Тесты

```bash
npm test --prefix server
```

Перед прогоном тестовая база `migom_test` пересоздаётся. Тесты проверяют регистрацию и вход, валидацию,
атомарное взятие заказа (несколько курьеров одновременно), «один активный заказ на курьера»,
начисление баллов по журналу, повторные оценки и параллельные покупки призов.

### Как устроены данные

- **Журнал баллов** (`PointsEntry`): баланс — это сумма записей. Записи только добавляются, у каждой есть причина и тип.
- **Взятие заказа** — условный `UPDATE ... WHERE status = 'new'`: заказ достаётся только одному курьеру.
  Частичный уникальный индекс не даёт курьеру держать два активных заказа.
- **Покупка призов** блокирует строку пользователя (`SELECT ... FOR UPDATE`), поэтому параллельные покупки не уводят баланс в минус.
- **История статусов** заказа хранится в `OrderEvent`.
- **Статистика** (доставки, километры, заказы) считается из данных, а не хранится счётчиками.

### Продакшен-сборка

```bash
npm run build
npm start
```

Сервер отдаст собранный клиент и API на http://localhost:3001.
